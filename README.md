# 🤖 Telegram Media Downloader Bot

ربات دانلود ویدیو و صدا از اینستاگرام، یوتیوب، تیک‌تاک و ۱۰۰۰+ سایت دیگه.

## ✅ قابلیت‌ها
- دانلود ویدیو با بهترین کیفیت
- دانلود صدا به فرمت MP3 با کیفیت 320kbps
- کار در پیوی و گروه‌های تلگرام
- پشتیبانی از YouTube, Instagram, TikTok, Twitter/X, Facebook, Reddit, ...

## 🚀 راه‌اندازی روی Railway

### 1. متغیر محیطی تنظیم کن
در Railway → Variables این رو اضافه کن:
```
BOT_TOKEN=توکن_ربات_تلگرامت
MAX_FILE_SIZE_MB=50
```

### 2. Deploy کن
فایل‌ها رو به GitHub push کن، Railway خودکار build می‌کنه.

## 📋 دستورات ربات
| دستور | توضیح |
|-------|-------|
| `/start` | شروع |
| `/help` | راهنما |
| `/audio [لینک]` | دانلود فقط صدا |
| `[لینک]` | دانلود ویدیو |

## ⚠️ نکات
- حداکثر حجم برای ربات‌های تلگرام: **50MB**
- برای فیلم‌های بزرگ‌تر نیاز به Premium API داری
